## First start, in short

1. Confirm the exact miner model and control board before installing anything. Packages are
   specific to both.
2. Install only a package built for that exact model and controller. See the
   [install guides](INSTALL/README.md).
3. Open the miner's dashboard. Mining starts off.
4. Review board detection, fan speeds and temperatures, then set a pool.
5. Press Start only after those checks look right.

Keep your original firmware and the recovery media for your control board.
